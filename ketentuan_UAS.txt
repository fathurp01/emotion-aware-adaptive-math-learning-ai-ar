==================================================
DESKRIPSI TUGAS
==================================================

Mahasiswa diminta membuat sebuah aplikasi berbasis Cloud Computing yang mendukung salah satu tujuan Sustainable Development Goals (SDGs).

Pilihan bidang SDGs yang dapat digunakan:

1. Kesehatan
   Contoh:
   - Diagnosa medis
   - Telemedicine
   - Monitoring pasien
   - Riset obat

2. Reformasi Birokrasi
   Contoh:
   - Digitalisasi administrasi publik
   - Sistem pelayanan masyarakat
   - E-government

3. Pendidikan
   Contoh:
   - Pembelajaran adaptif
   - Analisis akademik
   - LMS berbasis AI

4. Ketahanan Pangan
   Contoh:
   - Smart farming
   - Monitoring pertanian atau perikanan
   - Prediksi hasil panen

5. Mobilitas dan Kota Cerdas
   Contoh:
   - Smart transportation
   - Traffic management
   - Parkir pintar

==================================================
KETENTUAN INFRASTRUKTUR CLOUD
==================================================

A. Segmentasi VPC

Setiap komponen berikut harus ditempatkan pada VPC yang berbeda:

1. Frontend VPC
2. Backend VPC
3. Database VPC
4. Bucket / Storage VPC
5. AI Service VPC

Catatan:
AI Service VPC bersifat optional, tetapi direkomendasikan.

B. Multi-Cloud Requirement

Bucket atau Object Storage wajib menggunakan layanan cloud yang berbeda dari layanan utama aplikasi.

Contoh implementasi:

Contoh 1:
- Compute menggunakan AWS
- Bucket menggunakan GCP Cloud Storage

Contoh 2:
- Compute menggunakan Azure
- Bucket menggunakan AWS S3
